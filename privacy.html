Privacy Policy

Cornerstone Dismissal Board Launcher and Cornerstone Dismissal Sync (Chrome extensions)
Published by Cornerstone of Jacksonville, Inc. (Cornerstone Christian School) · Effective October 23, 2026

These extensions are internal tools for Cornerstone Christian School staff and classroom devices. They are installed by the school through Google Admin and are not intended for the general public.

Cornerstone Dismissal Board Launcher

  • What it does: opens the school's dismissal board (app.csjax.org/kiosk) full-screen on classroom devices during dismissal, and closes it afterward or when a teacher taps “Close board.”
  • Data collected: none. It does not collect, read, transmit, or sell any personal information, browsing history, or website content.
  • Data stored on the device: only today's date if a teacher closed the board (so it stays closed that day), and optional settings set by the school's IT administrator. This stays in Chrome on that device.
  • Website access: it runs only on app.csjax.org/kiosk, solely to make the “Close board” button work.

Cornerstone Dismissal Sync

  • What it does: on one school staff computer, it reads each homeroom's daily dismissal list from the school's KidAccount account and publishes it to the school's own dismissal boards.
  • Data handled: student names, homeroom teacher, and dismissal method (for example car number or bus number), as already recorded by the school in KidAccount.
  • Where it goes: only to the school's private database (Supabase), which is shown only on the school's campus network. It is not shared with or sold to anyone else and is not used for advertising.
  • Stored on the device: the upload key and schedule settings entered by school staff, plus the time and result of the last sync.

Student privacy

Student information is handled as an education record under the school's FERPA obligations, used only for daily dismissal, and kept only as long as needed for that purpose. Neither extension uses data for any purpose unrelated to dismissal.

Changes

If these practices change, this page will be updated and the effective date above will change.
